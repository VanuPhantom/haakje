Haakje

RxJS 💜 React

State management without all the fuss

Haakje is a state management and utility library for React, centered around using RxJS observables for global state management.

Why use Haakje?

In React, state management solutions don't tend to scale well.

  • Some involve large amounts of boilerplate
  • Some require highly opinionated architectural decisions to be made early on
  • Others rely on reactivity systems which are simple at first, but hard to reason about when a project grows

Haakje attempts to tackle this challenge by giving you a toolbox to build your own state management from the ground up.
